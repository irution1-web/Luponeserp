# 루폰스 정산관리

사내 주문관리 · 견적서 생성 · 매출/정산 ERP 시스템

## 주요 기능
- 팀원별 계정 로그인 (슈퍼어드민 / 팀원 권한 분리)
- 거래처 관리 (담당자 지정, 직원별 조회)
- 공급사 관리 (서비스 상품 · 원가 등록)
- 상품 관리 (카테고리 아코디언, 어드민 전용)
- 주문 등록 (판매/매입 분리 입력, 작업일수 → 마감일 자동 계산, 마진 자동 계산)
- 마감임박 알림 (D-3 이내 자동 알림, 관리자 → 직원 피드백 요청)
- 견적서 자동 생성 (목록 조회, 인쇄/PDF, 이미지 복사)
- 매출 ERP (기간별 조회, 거래처 순위, 직원별 정산 관리, 엑셀 다운로드)

## 실행 방법
`index.html`을 브라우저(Chrome 권장)로 열면 바로 실행됩니다. 별도 설치 불필요.

## 주의사항
- 데이터는 브라우저 메모리에만 저장되며 **새로고침 시 초기화**됩니다 (데모용).
- 실제 팀 공유 운영을 위해서는 서버/DB 연동이 필요합니다.
- 글꼴, 견적서 이미지 복사, 엑셀 다운로드는 인터넷 연결이 필요합니다.
